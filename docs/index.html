Numerical verification for heterogeneous compute · CPU · Metal · portable C · WebGPU

Prove the GPU agrees with the CPU. To the ULP.

One typed intermediate representation lowers to Metal, portable C, and WebGPU (WGSL) — and every kernel is diffed against a deterministic CPU reference under an explicit, stated tolerance. Not "looks close." Provable numerical parity, with the IEEE edge cases that break float agreement modelled honestly. Parity is necessary, not sufficient: two backends can agree on the same wrong answer. Where a family ships a higher-precision ground truth (as CompensatedSum does), the same doctor checks the answer is right, not merely reproducible.

The contract

Tolerance is stated, never hidden

Compare under exact, a default abs/rel bar, or ulp(n) — agreement to within n representable floats, at any magnitude. The scale-free, gold-standard bar.

Modelled honestly

The edge cases that break agreement

FMA contraction, denormal flush-to-zero, NaN-skipping fmin/fmax, ties-away rounding, signed zero — reproduced in the reference so the two sides actually agree.

Proven, not asserted

Passes are on-device parity tests

The compiler's optimisation passes are verified semantics-preserving by running before/after on the GPU and comparing bit-for-bit. ~746 tests, three backends.

Measured, not asserted

Where the GPU wins — and where it honestly doesn't.

Batch DSP on an Apple M3 Pro, release build, against a fair multithreaded CPU baseline. Reported the way you'd want a vendor to report: with the losses in the table.

Tiny / real-time-sized transform
GPU loses — dispatch latency dominates

Why show the losses? Because the product is trust. The wins are real and large where the work is compute-bound and batched; they collapse toward a wash on memory-bound ops and lose outright at real-time sizes. An earlier draft mis-measured against a debug build; it was caught and corrected. That is the whole point of the tool.

Signed & notarised · free to evaluate

Hand it to your agent, or run the CLI.

The MCP server and CLI ship as signed, notarised macOS binaries and prebuilt x86-64 Linux binaries — the CLI, MCP, and library build and pass their full test suite on both. Free to evaluate and for non-production use, plus a 7-day production trial; production beyond that needs a commercial licence. The source is closed; serious evaluators can review it under NDA. A hosted verification service — parity CI against your own kernels — is in early access.
