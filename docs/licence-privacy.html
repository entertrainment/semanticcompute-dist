Licence-service privacy

The signed SemanticCompute CLI, MCP, and Live distribution binaries contact the SemanticCompute licence service before a compute operation. The request contains the licence key, executable name, operation name, full release commit, a random persistent installation identifier, and an idempotency key.

Storage

The service stores a peppered SHA-256 hash of the licence key and a SHA-256 hash of the installation identifier. It stores entitlement state, device first/last-seen timestamps, operation checkout state, the build commit, and the resulting bounded licence receipt. It does not receive numerical inputs, candidate/reference arrays, emitted kernels, file paths, source code, or parity results.

Purpose and retention

This data is used to enforce expiry, trial credits, subscription access, installation ceilings, retry safety, and revocation. Entitlement and checkout records are retained for licensing, support, abuse prevention, and audit needs. Contact douglas@entertrainment.co.uk for an access or deletion request.

Local identity

The default installation identifier is randomly generated and stored at ~/.semanticcompute/device-id with mode 0600. It is not derived from hardware serial numbers. Removing it creates a new installation identity and may consume another device allowance.
